## 操作

- 滚动浏览；右侧竖向导轨跳转章节
- 主视觉 / 节气刷屏：自动轮播，也可用左右按钮、滚轮
- 报告：先按项目名筛选，点封面进入逐页阅读
- 阅读器内：`←` `→` 翻页、滚轮翻页、底部缩略图跳页、进度条拖动、`Home` / `End` 首尾、`Esc` 退出

## 技术

纯静态单页（HTML + CSS + 原生 JS），无构建、无外部依赖、断网可用。

- 全部图片与字体本地化，字体为 Noto Serif/Sans SC 子集化 woff2
- 首屏背景为纯 Canvas 矢量「41N 代号动能场」，不加载任何位图
- 设计方向：Ink & Vermilion（墨黑 · 纸白 · 朱红）编辑式版式

## 本地运行

双击 `打开作品集.bat`（或直接打开 `index.html`）。

> 整包需一起移动，`index.html` 必须与 `assets/`、`fonts/` 保持同级。
