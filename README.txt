殷俊 · 作品集 H5
================================

在线观看：https://oro41n.github.io/yinjun-portfolio/

一、打开方式
  · 双击「打开作品集.bat」即可在默认浏览器全屏观看（推荐，纯本地、无需联网）。
  · 或直接双击 index.html。
  · 全部图片与字体均已本地化，断网也能完整浏览。

  ⚠ 常见问题（图片看不见 / 页面空白）
  1. 必须保持 index.html 与 assets 文件夹、fonts 文件夹在同一目录，整包一起移动，
     不要只拷贝 html。图片加载失败时页面顶部会出现红色提示条。
  2. 若双击 index.html 后只看到提示「作品集数据未能载入」，
     说明浏览器拦截了本地脚本（个别浏览器对 file:// 有安全限制），
     改用「打开作品集.bat」启动即可。
  3. 不要把 assets 文件夹改名或移走，assets.js / catalog.js 里存的是相对路径。

三、操作
  · 滚动浏览；右侧竖向导轨可跳转章节。
  · 主视觉 / 节气刷屏：自动轮播，也可用左右按钮、滚轮。
  · 报告：先按项目名称筛选，点封面进入逐页阅读。
  · 阅读器内：← → 翻页、滚轮翻页、底部缩略图条点击跳页、
    进度条拖动 / 点击跳转、Home / End 首尾、Esc 退出；「⤢」切换缩放。
  · 物料：点击任意图进入灯箱放大。

四、首屏背景
   「41N · 项目代号」动能识别——把 41n 这三个字符本身当作视觉母题，做成专属的代号识别系统。
   上层是稳定的巨大空心字标（代号识别锚点），下层为纯 Canvas 矢量动能场，不加载任何位图，
   因此不会出现大图缩放位移时的抖动 / 纹理爬行。动能场元素：竖向数据列上沿 x 推进的能量波
   （纸白主波 + 朱红尾波，只改亮度不改位置）、匀速上升带拖尾的动能光点、行进虚线信号线
   与移动光头、四角套准十字与底边刻度尺、微型技术标注。
   系统开启「减弱动效」时自动切换为静态一帧，离屏自动暂停以省电。

   手机端适配：主视觉改回 16:9 横版 + contain，完整显示 2:1 原图不裁切；
   宣传册缩略图条改为横向滚动、网格列加 minmax(0,1fr)，避免撑破视口。

五、手机加载优化（三档图片）
   同一张图存了三档，浏览器按屏幕宽度自动挑最轻的那一档下载：
     assets_t/   480px 短边 WebP    9.8 MB  —— 缩略图条、小图位
     assets_m/   800px 短边 WebP   24.3 MB  —— 手机与平板主用档
     assets/    原始尺寸 JPEG     111.1 MB  —— 桌面端的阅读器大图
   默认只下载 480w / 800w 两档，手机上单个页面通常只取几百 KB。
   tiers.js 记录每张图的真实宽高比，用来给 <img> 预设 width/height，
   图片未到达时先占好位置，滚动不会跳动。
   （原始 JPEG 保留是为了桌面端放大阅读时仍能看清报告上的小字。）

六、技术
  纯静态单页（HTML + CSS + 原生 JS），无构建、无外部依赖。
  资源位于 assets/ assets_m/ assets_t/ fonts/ 子目录；assets.js / catalog.js / tiers.js 为索引数据。
  设计方向：Ink & Vermilion（墨黑 · 纸白 · 朱红）编辑式版式。
  兼容性兜底：不支持 IntersectionObserver 的旧浏览器/受限环境会自动改为「内容直接可见」；
  图片批量加载失败与数据脚本缺失都会给出明确中文提示，不会静默白屏。
  移动端阅读器自动改用 800w 档；桌面端仍取原始 1536px 图以保证文字清晰。
